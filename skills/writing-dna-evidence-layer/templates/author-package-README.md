# 作者文风知识包

本目录由三层组成：

- 原始层：raw/、_meta/
- 证据层：_analysis/、语料索引.md、证据与方法.md
- 结论层：语言DNA.md、文章结构模板.md、写作视角与认知框架.md、视觉风格指南.md、Writing-DNA.md

## 写作前推荐读取顺序

1. 五份核心蒸馏产物
2. 语料索引.md
3. 从 raw/ 选取与本次体裁和题材最接近的原文通读
4. 对有疑问的规则，通过证据与方法.md 和 _analysis/evidence-map.json 回查依据

证据层用于复核和导航，不替代原始语料，也不覆盖核心 Writing DNA。
